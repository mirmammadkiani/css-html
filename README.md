# webforus

اپلیکیشن اندرویدی آموزش اصولی **HTML و CSS** به زبان فارسی، کاملاً آفلاین و مبتنی بر استانداردهای رسمی وب (MDN Web Docs، WHATWG و W3C).

## ویژگی‌ها
- آموزش گام‌به‌گام و استاندارد از مبانی HTML5 تا Flexbox، CSS Grid و طراحی واکنش‌گرا
- ویرایشگر کد تعاملی همراه با پیش‌نمایش زنده و کاملاً آفلاین (`WebView`)
- آزمایشگاه آزاد (Playground) با امکان ذخیره و مدیریت کدهای شخصی
- مرجع سریع آفلاین تگ‌ها و ویژگی‌های استاندارد HTML/CSS
- رابط کاربری مینیمال (الهام‌گرفته از Notion) با فونت فارسی Vazirmatn و فونت کد JetBrains Mono
- بدون نیاز به اینترنت و بدون دسترسی‌های اضافی

## مشخصات فنی
- **زبان:** Kotlin
- **رابط کاربری:** Jetpack Compose + Material 3
- **شناسه برنامه:** `ir.mirmammad.webforus`
- **ذخیره‌سازی پیشرفت:** Jetpack DataStore Preferences
